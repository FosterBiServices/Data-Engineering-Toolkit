Optional. Each filter is a pandas condition with your new column names, for example amount > 0, status != "TEST" or order_date >= "2026-06-01". From the second one on, choose AND (both must pass) or OR (either can pass). A row with a missing value never passes that filter.

Your row count can’t grow: if the lookup file has two rows for one key, the script stops and says so. Rows with no match are reported.

Across rows

For work that compares rows with other rows. It runs after the cleaning, filters, duplicate removal and lookup above, and before the checks.

Fill a missing value from matching rows

A row missing the value takes it from another row that matches it, trying each line in order. Matching ignores capitals and extra spaces. A match is used only when every matching row has the same value; otherwise the row stays empty and a note lists the candidates. New columns say which row it came from and how it matched.
