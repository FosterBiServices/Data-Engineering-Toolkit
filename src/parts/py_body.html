Step3

    

      

        
Set it up

        

      


      

        
One notebook for every object. ADF runs it once per object and passes the object’s name and where its bronze file is. Column names become lower case with underscores, no spaces or special characters (safe for Delta), whatever the file holds. Silver writes <schema>.<object>; gold copies only the rows silver wrote since the last gold load.

        

          
          
        

        
        
        

          
          
          
        

        

          
Lookups (optional). Bring columns from another silver object into an object’s gold rows, for example a name from orders_names into orders. A left join: no row is lost, and the lookup keeps one row per key (the newest), so none is added.

          

          
        

        
With a business key, silver and gold merge on it (one row per key). Without one, each file’s rows are kept, and a rerun of the same batch replaces them instead of adding them twice.

      


      

        
Nothing to set. Bronze applies no business logic, filters or type changes. It adds _source_file, _ingest_ts and _batch_id, keeps rows that don’t fit in _rescued_data, and lets new columns in.
