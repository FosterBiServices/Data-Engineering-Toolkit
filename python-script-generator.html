Step1

Describe the file

The page can’t open your file, so you show it the header row and a few rows. It reads the column names and suggests a type for each.

  1. Open the file and copy the header row with the next few rows (in Excel, select the cells; in a text file, the lines).
  2. Paste them below. Five to twenty rows are enough.

The rows you paste aren’t kept. The page reads the column names and types from them and saves only those. Nothing is sent anywhere, and a Copilot prompt never includes them.

Choose and type the columns

The script reads everything as text, then converts each column to the type you set here. A value that can’t be converted is listed as a problem, never guessed.

Key: the column or columns that identify one row. Required: a row with no value there is a problem. Codes with leading zeros (ZIP, account numbers) are suggested as Text so the zeros survive.
