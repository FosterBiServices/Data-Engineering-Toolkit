Business key
The column or columns that identify one row. Needed for Merge and SCD Type 2.

          

        

        

          Columns to copy 
          

            
Every column is copied unless you turn it off. Leave out columns the target doesn’t need, especially personal data.

            

          

        

        
        

          Check the size and change rate (optional)
          

            
Run this on the source to decide between a full and an incremental load. As a guide: under about a million rows, a full load is simpler and usually fast enough; above that, load incrementally if there’s a reliable change column.

            

              
Volume query

              

            

          

        

      



      

        
Pipeline variables

        
Your own variables, with their default values. Use one in a folder or file name as {var:name}, or choose Pipeline variable for a dataset, notebook or logging parameter. A default is plain text: ADF never evaluates one that starts with @.

        

        

        
      

      

        
Logging

        
How a run is recorded, on success and on failure. Set it once: it is saved with your team standards and used for every pipeline.

        

          
          
          
          
        

        

          
Parameters it takes

          
One row per parameter: its exact name, and what the pipeline should pass. The same call is made on success and on failure, with the status and error message filled in to match.

          

        

        

      


      

        
Schedule, alerts and what runs next

        

          
          
          
          
          
        

        

          Run Databricks notebooks after the load (optional)
          

            
One notebook path per line, in the order they run (bronze, silver, gold). Each gets batch_id = @pipeline().RunId; a path containing “bronze” also gets source_path, pointing at what this run landed. The Python Notebook Generator writes notebooks that take exactly these.

            
            
          

        

        

          Team standards (names, retries, control tables; saved in this browser)
          

            
Set these once for your team. Every pipeline is named and built by them, and Check a pipeline checks against them.
